# VitaSync

Synchronisation des sauvegardes de **Persona 4 Golden** entre la version PC (Steam) et la PS Vita.

## État du projet

Initialisation : aucun code pour l'instant.

## Structure

- `Références initiales/Pc/` : copie de l'état de base des sauvegardes Steam (non versionnée).
- `Références initiales/Vita/` : état de base des sauvegardes PS Vita, à remplir une fois le jeu réinstallé (non versionné).
